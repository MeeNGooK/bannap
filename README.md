# 반납 (Bannap)

여러 도서관에서 대출한 책의 반납일과 반납처를 한 화면에서 관리하는 모바일 우선 PWA 프로토타입입니다.

## 주요 기능
- 반납일까지 남은 기간을 기준으로 한 우선순위 표시
- 도서관·반납 장소·반납일과 함께 책 추가
- 반납 완료 상태 관리, 임박 일정 필터, 날짜순 정렬
- 기기 로컬 저장소에 데이터 보관 및 안드로이드 설치 가능(PWA)
- 알라딘 베스트셀러 기반 도서 카탈로그 자동 갱신

## 실행
Node.js 20 이상에서 `npm run start` 후 `http://localhost:4173`을 여세요.
